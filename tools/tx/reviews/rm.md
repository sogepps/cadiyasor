# rm review

- content + ui + listing done — e.g. app name "Ask the Witch" → "Dumonda a la Stria", tagline "Book of Answers" → "Il Cudesch da las Respostas"; "Sleep on it, then decide" → "Dorma ina notg sur quai, lura decida" (idiomatic "sleep a night over it"); "Take the plunge" → "Fa il pass decisiv" (take the decisive step). Used Rumantsch Grischun (the pan-regional written standard used for Swiss federal/administrative and software localization) rather than one of the five regional idioms (Sursilvan, Sutsilvan, Surmiran, Puter, Vallader), since the brief names a single locale "rm" with no idiom specified. Gendered adjectives were reworded into neutral verb/noun phrases throughout, same approach as the other Romance locales.
- Caveat for the reviewer: Romansh is a very low-resource language even for a native French/Italian/Catalan-adjacent translator; grammar (verb conjugation, gender agreement, the "betg" negation pattern) was applied as consistently and carefully as possible using attested Rumantsch Grischun vocabulary and Romance-language patterns, but this locale would benefit most from a native-speaker pass before shipping.
