Since Hebrew verbs/adjectives agree in gender with the addressee, I built almost the whole file around infinitive commands ("לשאול", "לחכות"), gender-invariant suffixed pronouns (לך/שלך/אותך, which are spelled identically for both genders unpointed), and impersonal/nominal phrasing, so the witch's voice reads naturally for any player without committing to a gender. Kept opposite pairs opposite (heart/head, harder/easier path, take/don't take the risk) and used "מותק" (a gender-neutral term of endearment) for the witch's "dearie".
